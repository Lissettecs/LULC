# SSL4EO-L Sample Generation for Land Cover Chile

Workflow for generating, selecting, reviewing, and auditing sampling rectangles (2×2 and 3×3, `scale300`) for SSL4EO-L/Landsat multitemporal chips. Designed for annual land cover and land use classification of Chile (target 1996–2025), with MapBiomas Chile Collection 2 as reference for 1999–2024.

Run all commands from the root of this directory.

## Script pipeline (01–10)

Quick reference. Full examples in [scripts/README.md](scripts/README.md).

| Step | Script | What it does | Input | Output |
|------|--------|--------------|-------|--------|
| 01 | `01_gee_grid_characterization.py` | Characterizes candidate grids in Earth Engine (v3.1) and exports SHP to Drive | MapBiomas C2 assets, C3 ecoregions, MGRS tiles | `GEE_exports` folder in Drive |
| 02 | `02_download_grids_drive.py` | Downloads and packages shapefiles from Drive | `GEE_exports` (`scale300` prefixes) | `intermediate_files/gee_characterization/*.zip` |
| 03 | `03_rectangle_selection.py` | Balanced selection by 6 sample types + critical classes; anti-overlap within zone and UTM18/UTM19 border | 2×2 ZIP (`--homogeneo`) and/or 3×3 ZIP (`--mixto`) | `final_samples/seleccion_*` and `reservas_*` |
| 04 | `04_annotate_grid_taxonomy.py` | Adds N1/N2/N3 taxonomy columns (requires native C2 level-3 IDs) | Selection CSV/GPKG | `*_taxonomia_n3.csv` (or other input format) |
| 05 | `05_rectangle_selection_review.py` | Review tables and text report | GeoJSON/GPKG from `final_samples/` | `intermediate_files/review/` (`01_`–`09_`, `REVISION_COMPLETA*.txt`) |
| 06 | `06_balance_audit.py` | National balancing checklist vs operational targets | Selection GeoJSON | `intermediate_files/review/AUDITORIA_BALANCEO.txt` |
| 07 | `07_visualize_reports.py` | Streamlit dashboard for reports and maps | CSV reports + geometries | Interactive view or exported HTML |
| 08 | — | *No script.* Prefix `08_` identifies critical-class tables generated by step 05 | — | `08_clases_criticas_*`, `08_achaparrado_detalle_*` |
| 09 | `09_generate_rectangle_review_plan.py` | Defines `review_years`, rule, and priority per rectangle | Selection GeoJSON/GPKG | `plan_revision_UTM*_scale300.csv` |
| 10 | `10_consolidate_national_review_plan.py` | Merges UTM18/UTM19 plans and generates summaries | Per-zone plan CSVs | National plan + summary tables in `intermediate_files/review/` |

## Methodological principle

1. **Candidate grid** — universe of rectangles per UTM zone and size (2×2 homogeneous, 3×3 mixed).
2. **Selected rectangles** — balanced subset (~300–350 nationally) filtered by quality, ecoregion, class, stability, and change.
3. **Multitemporal chips** — final units derived from approved rectangles.

Core rule: all chips from the same rectangle inherit the same `split` (train/val/test). Script 03 assigns split at `grid_id` level with spatial cluster stratification to avoid leakage.

## Earth Engine inputs (script 01)

| Asset | GEE path |
|---|---|
| MapBiomas Chile C2 | `projects/mapbiomas-chile/assets/LULC/COLLECTION-02/CLASSIFICATIONS/classification-final/clasificacion-final-4` |
| Ecoregions | `projects/mapbiomas-chile/assets/LULC/COLLECTION-03/ANCILLARY_DATA/ECORREGIONES_RASTER/ecorregiones_col3_30m` |
| Chile MGRS tiles | `projects/mapbiomas-chile/assets/LULC/COLLECTION-03/ANCILLARY_DATA/Tiles_Chile_Sentinel` |

Characterization periods: P1 (1999–2005), P2 (2006–2012), P3 (2013–2018), P4 (2019–2024).

Key script 01 parameters:

- `--project mapbiomas-chile` (default GCP project)
- `--class-level n3` — native C2 level-3 IDs (recommended; export suffix is `_n3`)
- `--stats-scale 300` — statistical reduction scale
- `--rect-side 2` (homogeneous) or `3` (mixed)
- `--utm 18` or `19` (also 12, 17 for islands)
- `--run-scale300-all --wait --download` — all 4 runs + wait + automatic download

## Sample types (script 03)

Six essential types (temporal × spatial dimension):

| `sample_type` | Temporal | Spatial | Summary criterion |
|---|---|---|---|
| `estable_homogenea` | Stable | Homogeneous | `mode_pct ≥ 85`, stable run ≥ 5 years |
| `estable_simple_media` | Stable | Simple/medium | Stable mosaic 2–4 classes |
| `anual_homogenea` | Annual | Homogeneous | Pure class in one `ref_year` |
| `anual_simple_media` | Annual | Simple/medium | Annual dynamics in mixed context |
| `transicion_homogenea` | Transition | Homogeneous | Change between pure dominant classes |
| `transicion_simple_media` | Transition | Simple/medium | Change in mixed context |

Dedicated pools for critical classes: sand/beach/dune (23), salt flat (61), shrubland forest (67), northern forest and grassland. Cross-cutting classes (wetland, urban, fine agriculture, etc.) are excluded from the general model and reserved for specialized models.

`scale300` profile: national target **300–350** rectangles (~138 UTM18 + ~192 UTM19).

## Execution workflow

### 01 — Characterize grids in GEE

```bash
python scripts/01_gee_grid_characterization.py --authenticate
python scripts/01_gee_grid_characterization.py --project mapbiomas-chile --utm 18 --rect-side 2 --stats-scale 300 --class-level n3
python scripts/01_gee_grid_characterization.py --utm 18 --rect-side 3 --stats-scale 300
python scripts/01_gee_grid_characterization.py --utm 19 --rect-side 2 --stats-scale 300
python scripts/01_gee_grid_characterization.py --utm 19 --rect-side 3 --stats-scale 300
```

Integrated (export + wait + download):

```bash
python scripts/01_gee_grid_characterization.py --run-scale300-all --wait --download
```

### 02 — Download from Drive

```bash
python scripts/02_download_grids_drive.py --scale300-all
```

Downloads the 4 ZIPs with `homogeneo_2x2` and `mixto_3x3` prefixes for UTM18 and UTM19. Uses Earth Engine OAuth token (Drive scope).

### 03 — Select rectangles

```bash
python scripts/03_rectangle_selection.py \
  --homogeneo intermediate_files/gee_characterization/grilla_ssl4eo_muestras_homogeneo_2x2_UTM18_scale300_n3.zip \
  --mixto intermediate_files/gee_characterization/grilla_ssl4eo_muestras_mixto_3x3_UTM18_scale300_n3.zip
```

Relevant flags:

- `--no-auto-previous` — do not reuse previous selections from the same zone as overlap constraint
- `--previous archivo.geojson` — exclude already selected rectangles
- `--max-overlap 0.0` — overlap tolerance (default zero)

Repeat for UTM19. By default also avoids overlaps with the other zone's selection at the border.

### 04 — Annotate N3 taxonomy

```bash
python scripts/04_annotate_grid_taxonomy.py \
  -i final_samples/seleccion_grilla_ssl4eo_muestras_UTM19_scale300.csv
```

### 05 — Generate review reports

```bash
python scripts/05_rectangle_selection_review.py --utm 18 19
```

Produces, per zone and combined:

| Prefix | Content |
|---|---|
| `01_resumen_general` | Totals, split, tiers, mean quality |
| `02_por_tipo_muestra` | Counts by `sample_type` |
| `03_eco_x_clase_*` | Ecoregion × modal class |
| `04_eco_x_tipo_*` | Ecoregion × sample type |
| `05_clase_x_tipo_*` | Modal class × type |
| `06_grid_mode_x_tipo` | Grid mode × type |
| `07_split_x_tipo` | Split × type |
| `08_clases_criticas_*` | Critical class summary and detail |
| `08_achaparrado_detalle` | Shrubland forest detail |
| `09_calidad_por_tipo` | Quality metrics by type |
| `REVISION_COMPLETA*.txt` | Consolidated text report |

### 06 — Audit balancing

```bash
python scripts/06_balance_audit.py
```

Verifies 14 criteria, including:

- National total 300–350
- UTM18 (~100–130) / UTM19 (~140–180) balance
- Stable samples, homogeneous transitions, priority ecoregions (E7, E8, E9, E12, E15)
- Quotas for sand, salt flat, grassland, northern forest
- Split ~70/15/15 and zero overlap between zones
- Zero overlap between UTM18 and UTM19 (criterion [14])

### 07 — Visualize reports

```bash
streamlit run scripts/07_visualize_reports.py
python scripts/07_visualize_reports.py --export-html revision_dashboard.html
```

Reads `intermediate_files/review/`, geometries from `final_samples/`, and can overlay 1×1 chips (optional).

### 09 — Review plan per rectangle

```bash
python scripts/09_generate_rectangle_review_plan.py \
  -i final_samples/seleccion_grilla_ssl4eo_muestras_UTM18_scale300.geojson \
  -o intermediate_files/review/plan_revision_UTM18_scale300.csv
```

`review_rule` assignment by `dim_temporal`:

| Rule | When it applies | Typical years |
|---|---|---|
| `estable_anclas_temporales` | Stable rectangles | 1999, 2013, 2024 (or nearest stable years) |
| `anual_ref_year` | Annual types | Rectangle `ref_year` |
| `transicion_cambio_modal_entre_periodos` | Modal class change between P1–P4 | Windows at period boundaries |
| `transicion_anios_no_estables` | Years unstable relative to mode | ±1 year windows |
| `transicion_sin_anio_exacto_usar_anclas` | Transition fallback | Anchors 1999, 2013, 2024 |

Output fields: `review_years`, `n_review_years`, `review_rule`, `review_priority`, `review_notes`.

### 10 — Consolidate national plan

```bash
python scripts/10_consolidate_national_review_plan.py \
  --input intermediate_files/review/plan_revision_UTM18_scale300.csv \
          intermediate_files/review/plan_revision_UTM19_scale300.csv \
  --out-dir intermediate_files/review
```

## Minimum quality control

- Zero overlap between UTM18 and UTM19 (script 06, criterion [14]).
- Unique `grid_id` in national plan (script 10, `validate_outputs`).
- Split assigned at rectangle level, not chip-year level.
- Critical classes and priority ecoregions within targets.
- Rectangles with low `review_priority` reviewed at anchor years.
- No heavy files in the Git repository.
